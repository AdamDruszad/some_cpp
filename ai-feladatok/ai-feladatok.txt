4. Írjon programot amely beolvas egy szöveget (mondat.txt), 
és egy map<string,int>-ben megszámolja hogy melyik szó hányszor szerepel. 
Írja ki csökkenő gyakorisági sorrendben.
alma korte alma barack alma korte

5. Adott az alábbi kód. Mi lesz a kimenet? Magyarázd el soronként.
vector<int> v = {5, 3, 8, 1, 9, 2};
int max = v[0], maxind = 0;
int osszeg = 0;
int db = 0;

for(int i = 0; i < v.size(); i++){
    if(v[i] > max){ max = v[i]; maxind = i; }
    osszeg += v[i];
    if(v[i] % 2 == 0) db++;
}
cout << max << " " << maxind << endl;
cout << osszeg / (float)v.size() << endl;
cout << db << endl;
