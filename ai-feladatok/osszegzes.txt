Összegzés - számlák
Egy vektor összegzése feltétel nélkül

Adott egy vektor, amely egy bolt napi bevételeit tartalmazza (egész számokban, forintban):
{1200, 850, 3400, 920, 450, 1780, 2200}

Írj függvényt napi_osszeg(vector v) névvel, amely visszaadja az összes napi bevétel összegét!
A main()-ban írasd ki az eredményt!

Tipp (tétel)
Összegzés tétel: indíts egy 0-ás számlálóval, adj hozzá minden elemet.

==========MEGOLDAS-01==========

#include <iostream>
#include <vector>

using namespace std;

int napi_osszeg(vector<int> v){
    int ossz = 0;
    for(int x : v){
        ossz += x;
    }
    return ossz;
}

int main(){
    vector<int> v = {1200, 850, 3400, 920, 450, 1780, 2200};
    int a = napi_osszeg(v);
    cout << a;
}
